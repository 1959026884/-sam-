# 数据说明

## 合并分子清单_292.xlsx

每行一个分子，包含：

- `name`：分子名称，部分行为空或重复
- `smiles`：训练使用的唯一 SMILES
- `PCE_max`：两个来源数据集的 PCE 较大值，范围 1.3–27.2
- 两个来源 PCE 列及两个来源是否包含该分子的标记列

## pseudo_pairs.csv

- `smiles_A` / `smiles_B`：配对两端的 SMILES
- `y`：`1` 表示 A 的 `PCE_max` 高于 B，`0` 表示相反
- 每个无序配对正反各一行，共 34,368 行
- PCE 完全相同的分子对不包含在内

配对抽样算法未包含在本仓库中，重训时直接使用该 CSV。
