# 五折交叉验证记录

本次验证运行于 2026-11-13 至 2026-11-14，GPU 为 NVIDIA GeForce
RTX 3050 Laptop GPU，环境为 torch `2.14.1+cu130` 与 Optuna `5.0.0`。

## 文件

- `splits.json`：292 个分子的折归属、每个配对的验证折和目标端。政策为
  冷启动目标分子：目标分子不参与该折训练，参照分子可以是训练分子。
- `oof_predictions.csv`：全部 17,184 个配对的 OOF 预测、标签及是否属于
  严格双端未见子集。
- `summary.json`：逐折指标和汇总指标。
- `experiment_config.json`：轮数、折数、种子、设备和依赖版本。
- `wo_outer*.json` / `gt_outer*.json`：每个外层折的 Optuna 试验、剪枝
  状态与最优超参数。
- 完整训练日志、30 个折内检查点与 Optuna 数据库保留在本机运行目录
  `runs/sam_cv_5fold_20261113/`，未打包进 GitHub 发布目录。

## 关键口径

- 每个无序配对只评估一次；严格双端未见子集共 3,424 个配对。
- 最终 `checkpoints/` 的全数据模型采用折 3 的最优内层超参数。折 3
  外层冷启动 AUC 为 `0.8700`、严格双端未见 AUC 为 `0.7817`，请勿仅
  根据内层 AUC 解读该配置的泛化能力。
